# WiVRn FSR Spatial Stable Preview

This prerelease replaces the experimental frame-generation preview with a
stable, one-input-frame/one-output-frame spatial reconstruction path. All
upscaling is implemented in WiVRn's OpenXR runtime and headset client; streamed
applications such as VRChat are not modified or injected.

## Highlights

- Independent game, transport, and target resolutions.
- PC FSR1 and post-decode Quest SGSR1, FSR1, and NVIDIA Image Scaling modes.
- Automatic bitrate scaling based on the encoded area, with a manual mode.
- Persistent server sessions and late headset reconnection after the automatic
  retry window expires.
- Dropout filtering for simulated body trackers without hiding real movement.
- A working application launcher before the first streamed frame, including
  correct `wayvr --openxr` handling and visible launch errors.
- Frame generation and its temporal/color-only experiments have been removed.

## Downloads

- `WiVRn-fsr-spatial-v0.2.0-quest-arm64.apk`: optimized Quest APK, signed with
  the same development key as Preview 1 so it can upgrade that sideloaded app.
- `WiVRn-fsr-spatial-v0.2.0-linux-x86_64.AppImage`: portable command-line
  streamer built on Ubuntu 24.04. It starts `wivrn-server`; pass normal server
  flags directly to the AppImage.
- `WiVRn-fsr-spatial-v0.2.0-linux-x86_64.tar.gz`: relocatable server,
  `wivrnctl`, OpenXR runtime libraries, service metadata, and license notices;
  like the previous archive, it expects compatible system libraries.
- `SHA256SUMS`: checksums for all downloadable artifacts.

The headset APK and Linux streamer must come from this same release because
the paired protocol includes the negotiated spatial mode and resolution data.

## Install and run

```sh
adb install -r WiVRn-fsr-spatial-v0.2.0-quest-arm64.apk
chmod +x WiVRn-fsr-spatial-v0.2.0-linux-x86_64.AppImage
./WiVRn-fsr-spatial-v0.2.0-linux-x86_64.AppImage --no-fork
```

For the archive:

```sh
tar xzf WiVRn-fsr-spatial-v0.2.0-linux-x86_64.tar.gz
./usr/bin/wivrn-server --no-fork
```

The AppImage bundles most user-space libraries but still uses the host's
VA-API/NVENC, PipeWire, GPU driver, and system D-Bus services. Install the
matching GPU driver and enable the WiVRn firewall port on the host. The archive
is intended for a compatible Ubuntu 24.04-class environment or a system with
the corresponding WiVRn runtime dependencies installed.

## Recommended Quest starting point

- Game resolution: 80%
- Target resolution: 100-104%
- Spatial algorithm: Headset - SGSR1
- Refresh rate: 90 Hz
- FPS divider: 1
- Application SpaceWarp: disabled

## Validation

- Server tests, shader compilation, Android release build, APK signature, and
  archive/AppImage structure are checked before publication.
- Quest 3S reconnection, application selection, OpenXR first-frame transition,
  controllers, audio, and multi-hour VRChat use were exercised physically.
- `wayvr --openxr` detects the bundled WiVRn runtime.
